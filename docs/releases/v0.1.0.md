Tempo Time for macOS.

Select an audio input and channel to measure a click track and show note lengths in milliseconds. The meter and tempo detection run automatically. Tapping sets a manual tempo for 30 seconds while audio analysis continues.

Requires an Apple silicon Mac running macOS 13 or later. Allow microphone access when prompted.

Download `tempo-time-macOS.dmg`, open it, and drag Tempo Time to Applications. The app is ad-hoc signed and is not notarized. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway after attempting to open the app.

Tested with a 120 BPM click through a Core Audio virtual input and with the built-in microphone. External Dante/USB interfaces, sleep/wake recovery and macOS 13 hardware have not been independently verified.
